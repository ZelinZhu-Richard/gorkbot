# Uploaded Originals

Place scrubbed, unmodified source evidence here.

For each addition, include a small adjacent metadata file containing:

```yaml
source_name:
source_type:
original_date:
collected_date:
collector:
public_or_private:
permission_to_use:
contains_sensitive_data:
redactions_applied:
notes:
```

Never commit credentials, session cookies, access tokens, private customer records, or confidential documents.

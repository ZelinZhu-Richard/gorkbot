# Inbox

This directory contains project inputs, not authoritative architecture or product decisions.

## `prepared_materials/`

These are structured starter drafts prepared from the founder's stated goals and current public research. They contain confirmed decisions, provisional hypotheses, templates, and explicit unknowns.

Planning models must not treat provisional sections as customer evidence.

## `uploaded_originals/`

Place unmodified source material here, including:

- Grok Bot screenshots and recordings
- transcripts
- user interview notes
- prior code snapshots
- papers and reports
- UI references
- exports from other tools

Do not overwrite originals. Remove secrets and sensitive personal information before committing because this repository is public.
